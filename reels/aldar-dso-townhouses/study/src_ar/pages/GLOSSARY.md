# Arabic translation brief: Aldar Dubai townhouse study (A4 PDF, 16 pages)

Audience: Gulf investors and brokers. Register: clear, professional Modern Standard Arabic (financial-report style), not colloquial.
Translate EXACTLY what the English says: same facts, same numbers, same hedges ("analyst estimate", "not confirmed"). Do not add or drop claims.

## Hard rules
- Keep ALL HTML tags, attributes, class names, ids, img src and inline styles byte-for-byte. Only replace the human-readable English text between tags.
- Keep numbers in Western digits (0-9) exactly as written: 1,400–1,650 / 17.9 / +3.2% / 3,552 / 2026 etc. Never change a number.
- Currency: "AED 1,400–1,650" -> "1,400–1,650 درهم"; "AED 17.9bn" -> "17.9 مليار درهم"; "AED 3.2–3.8m" -> "3.2–3.8 مليون درهم"; "AED/sq ft" -> "درهم/قدم²". "per sq ft" -> "للقدم المربعة".
- Dates: "16 Oct 2026" -> "16 أكتوبر 2026"; months: يناير فبراير مارس أبريل مايو يونيو يوليو أغسطس سبتمبر أكتوبر نوفمبر ديسمبر. "H1 2026" -> "النصف الأول 2026"; "Q3 2026" -> "الربع الثالث 2026".
- Sources page: keep newspaper/website names and quoted article titles in English (they are references), translate everything around them. Keep URLs unchanged.
- Keep "n=" counts as "n=". Keep "%" after the number (+9.5%).
- Short labels in headers/footers: translate (e.g. "ALDAR · DUBAI TOWNHOUSE STUDY" -> "الدار · دراسة التاون هاوس في دبي"; "Analyst study · 16 October 2026 · not investment advice" -> "دراسة تحليلية · 16 أكتوبر 2026 · ليست نصيحة استثمارية").
